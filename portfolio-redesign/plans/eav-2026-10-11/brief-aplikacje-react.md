## Anty-kanibalizacja (ważne)
Na stronie są osobne usługi: tworzenie stron Next.js (główna strona Next.js: strona lub aplikacja firmowa od zera), headless WordPress, aplikacje React (panele za logowaniem), strony Jamstack (statyczne strony z CMS), outsourcing Next.js (dla startupów i zespołów), nowoczesne strony internetowe (design, animacje, dostępność), strona internetowa dla małej firmy (prosty zakres, WordPress), tworzenie stron www (ogólna). Ta strona trzyma się TYLKO swojego tematu; inne odeślij jednym zdaniem.

Czytelnik: firma, która ma już system lub API (ERP, CRM, własny backend) i potrzebuje wygodnego panelu dla pracowników albo klientów, albo zespół, któremu brakuje rąk do frontendu w React.
Frazy wspierające: programista React, aplikacja React, panel administracyjny React, frontend React, React TypeScript.

## Audyt EAV
Encja: usługa zbudowania aplikacji lub panelu w React do istniejącego zaplecza. Predykaty: zbuduję interfejs, połączę z API, przetestuję, przekażę kod.
1. Ludzki ton: co zyskują użytkownicy panelu (mniej kliknięć, mniej błędów przy wpisywaniu danych), nie lista bibliotek.
2. Atrybuty z wartościami: React z TypeScriptem, formularze z walidacją, tabele z filtrowaniem i stronicowaniem, role i uprawnienia, połączenie z REST API lub GraphQL, testy w miejscach, gdzie błąd kosztuje (formularze, obliczenia), kod w repozytorium klienta z opisem uruchomienia.
3. Konkret: panel admina w Galabau Darius (logowanie Clerk, zarządzanie treścią), komercyjne doświadczenie od 2020 roku (etat frontend developera w software house we Wrocławiu).
4. Kiedy NIE sam React: gdy potrzebne są publiczne podstrony pod Google, wtedy Next.js.
5. Termin: aplikacja lub MVP zwykle 6-12 tygodni; koszt bez kwot, główny czynnik: liczba ekranów z logiką i integracji z API.
6. Blok: jedna tabela „React czy Next.js: kiedy który”.
