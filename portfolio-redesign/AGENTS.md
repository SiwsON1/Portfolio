# Routemapa projektu

Przed rozpoczęciem pracy nad usługami, ofertą albo nowymi podstronami przeczytaj
`ROUTEMAPA.md` w katalogu głównym. Zawiera kierunki zarobkowe, ustalone widełki
cenowe i kolejność działań. Aktualizuj ją, gdy coś zostanie zrobione albo zmienione.

Reguły projektu, których nie łamiemy:
- anty-kanibalizacja: sprawdź `metaTitle` w `lib/services.ts` przed pisaniem nowej strony
- wizualna weryfikacja 3 rozdzielczości razy 3 iteracje przed uznaniem UI za gotowe
- commity bez trailera Co-Authored-By
